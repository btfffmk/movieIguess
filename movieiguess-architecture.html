Nebula Architecture

Vite-built movie discovery SPA served by a Cloudflare Worker

Application

  • • Vanilla ES modules with hash routing
  • • TMDB metadata is fetched in the browser
  • • Profiles and libraries stay in localStorage
  • • Legacy pages stay outside the production build

Build & delivery

  • • npm test checks core and download contracts
  • • Vite emits the production-only dist directory
  • • Wrangler deploys dist to the movieguess Worker
  • • Worker serves nebula.btfm.uk and movies.btfm.uk

Observability

  • • Route events contain no profile or title data
  • • Analytics counts route, country and hostname
  • • HTML logs sample country and status
  • • Queries, cookies and IPs are omitted
